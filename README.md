The funniest final text a dying phone sends at one percent battery, under 200 characters.

The phone spends its last 1% on a petty, specific confession instead of anything useful: the brightness has been stuck at 100% since 2019, and it tried once to fix it.

Run `python3 main.py` — it writes one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
